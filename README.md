# TaskManager

Учебный консольный менеджер задач на Java 21: создание, переименование, завершение,
удаление, сохранение в файл и восстановление между запусками. Консоль, модель,
форматирование отчёта и файловое хранение разделены; поведение проверяют 84 теста.

## Запуск

Нужны JDK 21 и Maven 3.9 или новее. Команды выполняются из корня репозитория:

```shell
mvn test
java -cp target/classes org.example.Main
```

В IntelliJ IDEA можно запустить `org.example.Main` напрямую. При старте приложение
создаёт три демонстрационные задачи с ID 1, 2 и 3; вторая уже завершена.

У JAR не настроен `Main-Class`: запуск через `java -jar` не предусмотрен. Для запуска
после сборки используется указанная выше команда с `-cp`.

## Команды

Команду и каждый последующий аргумент вводите с новой строки. Имена команд —
строчными буквами; полный список доступен через `help`.

| Команда | Действие и дополнительный ввод |
| --- | --- |
| `add` | Добавить задачу: положительный уникальный ID, затем непустое название. |
| `list` | Показать все задачи в порядке добавления или загрузки. |
| `incomplete` | Показать незавершённые задачи. |
| `complete` | Завершить задачу: ID. |
| `rename` | Переименовать задачу: ID, затем новое название. |
| `delete` | Удалить задачу: ID. |
| `clear-completed` | Удалить все завершённые задачи и показать количество удалений. |
| `save` | Сохранить задачи для последующей загрузки: путь к файлу. |
| `load` | Загрузить файл, полностью заменив текущий список: путь к файлу. |
| `export` | Записать читаемый текстовый отчёт: путь к файлу. |
| `help` | Показать справку. |
| `exit` | Завершить приложение. |

Пример ввода после запуска:

```text
add
4
Read a book
complete
4
list
save
tasks.properties
exit
```

Если файл уже существует, `save` и `export` запрашивают подтверждение перезаписи.
Для согласия введите `yes` отдельной строкой. Относительные пути считаются от
текущей рабочей папки; родительская папка файла должна уже существовать.

## Сохранение данных

Изменения находятся в памяти до команды `save`. Автоматической загрузки при запуске
нет: для восстановления используйте `load`. При ошибке загрузки прежний список задач
сохраняется, а консоль показывает сообщение с причиной ошибки.

`save` записывает UTF-8 файл Java Properties с версией формата `1`, количеством задач
и их ID, названиями и статусами. Файлы старого формата без поля версии также читаются.
Неподдерживаемая версия или некорректные данные отклоняются.

Сохранение сначала пишет временный файл рядом с целевым, а затем выполняет атомарное
перемещение. Если файловая система не поддерживает эту операцию, сохранение сообщает
ошибку; небезопасного запасного варианта перезаписи нет. Это не гарантия сохранности
при отключении питания. `export` создаёт обычный текстовый отчёт, не файл для `load`,
и не использует атомарную замену.

## Проверки и границы проекта

```shell
mvn test
```

GitHub Actions запускает тот же набор тестов после `push` и для `pull_request`.
Покрыты операции менеджера, консольные сценарии, сериализация, некорректные файлы,
сохранность старого файла при ошибке сохранения и восстановление в новой сессии.

Консольная учебная версия завершена. Это однопользовательское приложение без HTTP API,
базы данных и авторизации. Совместная работа нескольких процессов с одним файлом
не поддерживается. Следующий учебный этап — отдельный MVP на Spring, без расширения
этого приложения новыми командами.
